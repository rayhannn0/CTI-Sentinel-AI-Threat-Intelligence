# MongoDB Lab 13 — Replica Set, Monitoring, Kubernetes StatefulSet

## One-directory ZIP structure
- 01_Lab_13_1: authenticate and verify 3-node Docker replica set
- 02_Activity_13_1_Try_It_Yourself: Prometheus exporter metrics probe
- 03_Lab_13_2: Kubernetes Service + StatefulSet + PVC + shared keyfile Secret static checks
- 04_Activity_13_2_Try_It_Yourself: operational comparison
- failover_test.py: actual stepDown and PyMongo failover demonstration
- k8s/: manifests + instructions for real Kubernetes deployment and pod deletion
- output/: measured JSON is generated by local execution

## Mac commands (run in Terminal, NOT VS Code Run Code)
```bash
cd ~/Downloads/lab13/Lab13_MongoDB_Docker
python3 bootstrap.py
docker compose --profile runner build labrunner
docker compose --profile runner run --rm labrunner
# actual election/failover proof
docker compose --profile runner run --rm labrunner python failover_test.py
# exporter may require pulling a separate Docker Hub image
docker compose --profile monitoring up -d mongodb-exporter
docker compose --profile runner --profile monitoring run --rm labrunner python 02_Activity_13_1_Try_It_Yourself/activity_13_1.py
```

Check exporter at http://127.0.0.1:29216/metrics; the exporter needs an authenticated monitoring URI (the sample reuses admin for a self-contained lab, which is NOT production least privilege). In production create a read-only exporter role, rotate credentials and restrict metrics endpoint.

## Viewing with MongoDB Compass
One-node DIRECT access: `mongodb://127.0.0.1:27717/?directConnection=true&authSource=admin` with username `lab13_admin` and ROOT_PASSWORD from `.env`. Compass may show only one node in direct mode; 3-node health must be checked through rs.status() or scripts inside Docker.

## Security and scope
This is a LAB demonstration, not an independently certified production deployment: no default TLS, no external secret manager, no automated backup or disaster recovery. Do not expose replica set to the internet. Keyfile generated with Python cryptographic RNG and stored locally; the reference command `openssl rand -base64 756 > keyfile` also works with `chmod 400 keyfile`.

Kubernetes instructions: `k8s/README.md`. K8s is NOT marked as tested merely because Docker runs. Kubernetes needs a separate local or cloud cluster.
